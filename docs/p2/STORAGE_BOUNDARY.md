# 로컬 저장 경계

서버·계정·공유 저장이 아니다. 동일 브라우저 프로필/동일 origin에서 하나의 맵을 P2 전용 키에 저장한다. 스키마 version1이며 format=map-workspace-map-local. P1 mock,제품 backup,legacy 파일은 가져오기 거부한다. 최대1MiB,500노드/1000연결/50그룹. 필드 allowlist, 문자열/유한좌표/선택·연결·그룹 참조,ID/관계 중복,프로토타입 위험 키를 검사한다. 임의 HTML·URL을 실행하지 않는다.

LocalStorage 선택: P2의 제한된 단일 문서와 동기 쓰기/즉시 read-back 검증을 단순하게 구현할 수 있다. 대형 자료·다중 문서·계정별 초안은 P3/P4에서 IndexedDB repository로 별도 전환한다. LocalStorage는 보안 보관함이 아니며 브라우저 정리/프로필 삭제로 사라질 수 있다. 로컬 파일 다운로드를 회수 경로로 제공한다.

400ms 변경 후 debounce 자동 저장. 드래그 중은 저장하지 않고 종료된 명령을 저장한다. setItem과 getItem 동일값 확인 후에만 “이 기기에서 저장됨”. 실패하면 현재 메모리 초안을 유지하고 재시도/다운로드/복구를 표시한다. 저장 전 화면 view를 포함해 전체 문서를 다시 검증한다. 이력은 저장하지 않는다.

키: map-workspace:p2:map-local:v1 (현재), :previous (직전 정상본), :quarantine (명시 복구 시 원본 두 슬롯). 정상 현재본을 이전 슬롯에 쓴 뒤 새 현재본을 쓴다. 쓰기 실패 시 새 저장 성공으로 표시하지 않는다. 손상 현재본은 정상 이전본 위로 회전하지 않는다. 복구는 원본 격리 기록 성공 후 현재본 교체, 실패 시 교체 중단. 격리 슬롯은 최신1개이므로 다시 교체 전 원문 회수를 안내한다.

손상 로드: 가능하면 이전 정상본을 메모리에만 열고 자동 저장을 차단한다. 둘 다 불가하면 샘플을 임시로 보여 주며 원래값은 보존한다. 업로드 파일은 크기→JSON→형식/버전→참조 검증→미리보기→사용자 교체 확인 순서다. 무효 파일은 현재 초안·정상 저장본을 바꾸지 않는다. 가져온 문서로 교체도 세션 Undo 가능하다.

다른 탭의 storage 이벤트 또는 예상 원문 불일치가 감지되면 저장을 중단한다. 이는 서버 원자 CAS가 아니며, 동시 탭 read/write의 완전한 원자성을 보장하지 않는다. 다중 탭 동시 편집은 지원 범위 밖이다. 다른 탭 변화에서 내 초안 다운로드 후 새로고침/명시 교체를 안내한다. D-02 실제 서버 CAS와 계정 격리는 P4에서 검증한다.

저장 전 이탈은 beforeunload 경고를 요청하지만 브라우저 강제 종료/크래시의 최근400ms 초안을 보장하지 않는다. quota/security 오류는 UI로 노출한다. 로컬 저장 성공이 백업·서버 동기화 보장을 의미하지 않는다.
