# 용어

|표현|뜻|혼동 금지|
|---|---|---|
|맵|요소·관계·맥락을 담는 문서|업무대시보드 아님|
|요소/노드|맵의 개념·정보|계정 아님|
|연결선|방향과 이름을 가진 관계|업무 선행관계와는 별개|
|그룹|공간적으로 묶은 영역|권한 경계 아님|
|결정 상태|제안/검토중/확정/기각/대체|업무 완료와 별개|
|업무 상태|대기/진행중/완료/차단|결정 확정과 별개|
|담당자 명부|업무·요소 담당을 표시하는 사람 목록|로그인 권한을 주지 않음|
|팀 초대|확인된 회원에게 프로젝트 역할 부여|공개 링크 아님|
|공개 스냅샷|명시적으로 발행한 읽기 사본|원본 변경 자동 반영 아님|
|내 초안|아직 서버에 확정되지 않은 내 변경|서버 최신본과 별도|
|재시도|최신본 확인/명시적 재적용 후 저장|무조건 덮어쓰기 아님|
