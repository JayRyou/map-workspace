# 프로토타입 실행·검수 안내

1. map-workspace-p1-prototype.zip을 폴더째 풀고 prototype/index.html을 브라우저로 연다. ZIP 내부 파일을 바로 열지 않는다.
2. 기본 화면에서 요소·연결 이름·그룹을 선택한다. 우측 Inspector에서 연결된 기록으로 이동한다.
3. 상단 상태 시나리오에서 충돌/오프라인/권한 회수를 선택한다. ‘변경 확인’에서는 서버 최신본을 먼저 확인한 후 재시도가 열린다.
4. 역할을 보기 전용으로 바꾸고 편집 버튼, 팀원 초대, 공개 발행 제어를 비교한다.
5. 팀원과 공유를 각각 열어 로그인 협업과 별도 공개 스냅샷의 차이를 살핀다.
6. 내보내기에서 고정 선택 샘플의0/1-hop Markdown과 JSON 미리보기를 확인한다. 다운로드는 실제 사용자 데이터 백업이 아닌 샘플만 생성한다.
7. 모바일은 메뉴(☰)와 목록을 사용한다. ‘데모 살펴보기 → 빈 화면·오류·운영 시나리오’에 예외 경로를 모았다.

선택적으로 prototype 폴더에서 `python3 -m http.server 8000`을 실행하고 localhost:8000을 연다. 서버 프로그램은 필수가 아니며 정적 파일 제공만 한다. 외부 로그인·API·DB·CDN·키가 필요 없다. S3 등에 업로드 가능한 상대 경로이나 이번 작업에서 실제 배포는 하지 않았다.

화면의 입력/확인은 검토용이다. 새로고침하면 모든 상태가 초기화된다. 개인정보나 실제 비밀번호를 입력하지 않는다. 데모에 권한 강제나 보안 기능은 없다.

폰트: Noto Sans KR400/600, SIL Open Font License1.1. 로컬 woff2와 라이선스를 assets/fonts에 함께 포함했다. 외부 글꼴 요청 없음. 아이콘은 기본 문자와 자체 SVG이며 외부 이미지 없음.
