맵 삭제는 프로젝트 관리/항목 삭제 영향 및 이력·복구 설계에 포함한다. P1에서는 어떤 객체도 생성·수정·삭제하지 않는다. Undo/Redo는 비활성 이력과 입력 대안의 화면 설계이며 실제 엔진은 없다. 대규모500노드 성능, 원자성, import migration 정확성, 법적 문구는 미검증이다.
