# 디자인 가드레일

1. 캔버스 너비는1440px에서60% 이상. sidebar184px,Inspector320px를 사용하면936px=65%다. 실제 측정 결과로 검증한다.
2. 라이트 중립색,선택 파랑1색,작은radius4~6px,1px구분선. 큰 Hero/KPI·그라데이션·글래스·글로우 없음.
3. 노드는 제목/타입/요약/상태만,긴 설명은Inspector. 관계 라벨은 선과 별도로 읽힌다.
4. 결정 ‘확정/검토 중’과 업무 ‘완료/진행 중/차단’을 독립 표시한다.
5. 기능을 시뮬레이션할 때 ‘예시/데모’를 붙인다. 화면 상시 안내: P1 UI 데모 · 실제 데이터 저장/권한 검증 없음.
6. 버튼은 동작이 있거나,불가 이유와disabled 상태를 제공한다. 실제 생성/저장/인증/결제 성공처럼 속이지 않는다.
7. 모바일은 기본 요소 목록+상세 탐색. 캔버스를 작게 줄여 글자를 읽지 못하게 하지 않는다.
8. 모든 원격 데이터/API 없음. Noto Sans KR을OFL로로컬번들,직접작성SVG선/도형 사용. 이미지 장식과 외부폰트CDN 없음.
