가정 정합: 담당자 명부의 ‘서윤’과 로그인 팀원의 ‘서준’은 다른 사람이다. 명부와 계정을 자동 연결하지 않는다. 결정 2건·업무 3건 중 맵에는 대표 결정 1건·업무 1건만 표시한다. 전체 수와 맵에 배치된 수를 구분한다.

원본 코드·데이터는 보존한다. 실제 CRUD·인증·저장·메일·배포·과금·외부 AI 호출은 모두 후속 단계이며 본 산출물에 없다.
