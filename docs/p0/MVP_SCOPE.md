# 결정 상태 안내

D-01~03은 잠정 결정이며 최종 확정이 아니다. 아래 원문 제안은 이 문서 말미의 보완 기준으로 구체화한다.

# MVP 범위와 경계

상시 규칙의 필수 항목을 모두 Must에 보존했다. 아래 “Should”는 Must 완료 후 승인된 페이즈 범위 안에서만 검토하며 자동 추가하지 않는다.

|분류|포함|명확한 경계|
|---|---|---|
|Must: 계정/소유권|이메일 가입·확인·로그인/로그아웃·재설정, 워크스페이스/프로젝트 소유권|담당자 명부는 계정 아님; 인증 제공자 사용|
|Must: 맵 엔진|맵/노드/그룹/연결 CRUD, 좌표·확대·이동·선택·Undo/Redo, 인접 탐색|일반 관계 순환 허용; 그룹 1단계만, 중첩 Later|
|Must: 맥락|설명·타입·텍스트/숫자/날짜/선택/URL 속성, 메모, 결정·근거·미결정 논의|실행 코드/임의 HTML/첨부 바이너리 제외|
|Must: 업무|업무 CRUD·담당자·상태·기한·노드 연결·선행관계|업무 없이도 맵 사용 가능; 복잡한 간트 제외|
|Must: 저장/협업|서버 자동 저장·revision·초안·409 해결·권한·초대·읽기 공유|동시 편집 충돌 감지 방식; 자동 병합·익명 편집 제외|
|Must: 데이터 이동|JSON 백업/복원·schema 호환·미리보기·기존 두 포맷 변환|원본 덮기 기본 금지; migration은 명시적 실행|
|Must: AI 활용|선택 영역과 연결 노드 Markdown export|일반 Markdown으로도 유용; AI 호출/자동 전송 없음|
|Must: 운영/상용 준비|서버 제한·오류/모니터링·복구·Free/Pro/Team·결제 테스트|실제 판매·배포·외부 비용은 해당 페이즈 승인 후|
|Should|기본 템플릿 3종, 단축키 검색, 선택한 레이아웃 저장, 간단 정렬|범용 엔진 위 데이터 presets; 새 편집 엔진 아님|
|Later|CRDT·실시간 커서·채팅·Agent 실행·AI API·모바일 앱·간트·분석·시장|별도 PRD·비용·보안 검토 필요|

초기 템플릿은 시스템 맵/팀 기획/학습 정리로 제안한다. 별도 도메인 기능 없이 노드 타입·설명·관계·그룹 preset만 둔다. RWA 템플릿을 기본 홈에 강제하지 않는다.

## 공통 안전 상한 제안

한 맵의 UTF-8 직렬화 본문 1MiB, 노드500, 연결1,000, 그룹50, 업무200, 결정100. 중첩 그룹 없음. label200자, description10,000자, 사용자 속성 최대30개/요소, 문자열 속성2,000자, 외부 URL10개/요소, 전체 import10MiB. 어떤 상한이든 먼저 도달하면 거부한다. 업무·결정의 대량 사용은 프로젝트의 여러 맵으로 분리한다. 상한은 P2 성능 검증 및 P4 서버 검증 후 조정하며 상용 SLA가 아니다.

삭제는 휴지통으로 30일 유지한다. 프로젝트 보관은 읽기 전용이며 과금 저장량에 포함한다. 플랜 초과 시 신규 생성/증가 저장만 차단하고 읽기·export·축소·삭제·복구 가능한 범위를 설명한다. 동결 때문에 사용자가 데이터를 회수하지 못하게 하지 않는다.

## 범위 변경 절차

기능 ID, 사용자 가치, 기존 Must 영향, 데이터/권한/비용 변화, 해당 페이즈 테스트와 승인자를 CHANGELOG에 기록한 뒤 승인받는다. 일정이 부족하면 Should/Later를 줄이며 인증·서버 권한·충돌 보존·복원을 임의 제외하지 않는다.


## 잠정 정책의 범위

D-01 공급자 선택은 P4 진입 전 Spike 조건부다. D-02는 충돌 인지·내 초안 보존·명시적 재시도까지 Must, 자동 병합/CRDT는 Later다. D-03은 비공개 기본·초대 회원 역할·별도 공개 읽기 snapshot을 Must로 하며 공개 만료/해지·민감 필드 제외·명시적 갱신을 포함한다. 플랜별 공유 횟수와 만료 옵션의 상품 차등은 아직 가설이다.
