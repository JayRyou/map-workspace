## 플랜 초안

과금 단위는 workspace. Pro는 개인 소유 workspace, Team은 팀 workspace. 사람은 여러 workspace에 참여할 수 있으나 플랜은 합산되지 않는다. 편집 가능 좌석(owner/admin/editor)을 유료 좌석으로, viewer는 무료 제한 좌석으로 제안한다.

|항목|Free|Pro|Team|
|---|---|---|---|
|월 가격 가설|0원|8,900원/workspace|9,900원/편집 좌석, 최소3석|
|프로젝트/맵|2 / 5|20 / 100|100 / 500|
|편집 가능/보기 멤버 총원|소유자 포함4 / 5|소유자 포함4 / 20|계약 좌석3~50 / 100|
|텍스트 저장량|10MiB/workspace|100MiB/workspace|1GiB/workspace|
|공유|초대 보기/편집, 읽기 링크 생성·해지|동일+링크 만료 설정|동일+관리자 링크 정책|
|이력|7일 내 최대10개/맵|30일 내 최대50개/맵|90일 내 최대100개/맵|
|JSON/Markdown export|허용, 인위적 월 횟수 제한 없음|동일|동일|
|결제|없음|월 구독; 연간 할인은 검증 후|편집 좌석 월 구독|

맵 개수와 저장량은 동시에 적용한다. 현재 데이터·이력·휴지통을 모두 사용량에 포함하고 재생성 가능한 개인 view state는 별도 작은 상한을 둔다. node/edge 기술 상한은 전 플랜 공통이며 비싼 플랜이 자동으로 대형 캔버스를 안전하게 만들지는 않는다. 이력 보존은 날짜/개수/바이트 중 먼저 도달하는 한도, 생성 직전 사용자에게 설명한다. 버전 수와 일수는 모든 중간 자동 저장을 무기한 보관한다는 의미가 아니다. 일반 자동 저장 revision은 증가하되 오래된 스냅샷은 정책에 따라 정리한다.

Free에서도 3~4인 공동 작업을 검증할 수 있도록 기본 편집 초대를 제한적으로 허용한다. 보안·데이터 회수·정확한 Markdown export를 유료 장벽으로 삼지 않는다. Team의 지불 가치는 팀 규모·통제·이력·용량이다.

## 비용·남용·검증

COST_COMPARISON 기준의 1,000MAU에서 권장안 기본 인프라는 인증 무료 한도 미적용 약 $21.2/월, 적용 가능하면 약 $6.2/월이다. 이는 평균 사용량 가정의 총액이며 무료 계정 하나의 최대 비용이나 인건비 포함 원가가 아니다. 유휴 계정·공유 조회·악성 요청·대형 맵·백업 증가가 발생하면 달라진다. 실제 단위 원가는 월 총 인프라/활성 workspace, 저장량/retained account와 함께 측정한다.

Free 자동 저장5,000회/workspace/월, Pro50,000회, Team250,000회를 초기 남용 상한 가설로 두되 서비스 부하 측정 후 조정한다. 사용자 API 기본60회/분·쓰기30회/분, 초대10회/일/workspace(Team50), 인증 이메일5회/시간/계정·IP 조합을 검토한다. 초과 시429/Retry-After, 로컬 초안 유지, 읽기/export 유지. 분산 공격과 초대 토큰 조회에는 별도 IP·workspace 키 제한이 필요하다.

P7에서 업그레이드·좌석 증감·해지 예약·실패 결제·중복/역순 webhook·재구독·다운그레이드 데이터 보존을 샌드박스 검증한다. 결제 UI success만으로 권한을 올리지 않는다. 서명 검증 webhook과 idempotency로 서버 entitlement를 갱신한다. 실판매·세금·환불 문구는 P7 승인 대상이다.

검증 가설: 4인 팀3곳이 2주 이상 공동 저장을 사용하고 그중2곳이 용량/이력을 유료 가치로 선택하면 가격 인터뷰를 확대한다. 인터뷰·실험은 아직 수행하지 않았다.
