|US-11|관리자|멤버 권한 회수→초대/링크 확인→감사 이벤트 조회|다음 API부터 접근 차단|로그인 token 유효성만으로 접근 지속 금지|

각 시나리오는 ACCEPTANCE_CRITERIA의 페이즈 테스트로 연결된다. 사용자 인터뷰 검증 상태는 UNVERIFIED이며, 프로토타입 자동 테스트 통과로 이 SaaS 시나리오를 통과했다고 간주하지 않는다.
